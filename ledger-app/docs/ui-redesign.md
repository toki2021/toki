# 温暖生活界面更新

首页按月份展示摘要与账单，支出不扣退款，退款另列。当前月日均按已过天数，历史月按整月天数计算。月份范围采用本地时区的起点包含、终点不包含规则。

## 界面与兼容

- 统一米白背景、白色卡片、暖橙强调色；深色跟随系统。
- 四个底部入口：账单、统计、待确认、设置。规则与分类管理位于设置；原有导入、备份、识别逻辑和数据库结构保留。
- 首页摘要随账单滚动，月份栏固定；分类以 ID 筛选，支持未分类及筛选空状态。
- 账单行隐藏删除按钮，长商户名省略；小屏、大字体与大金额使用上下排版。退款使用文字和正号标识。
- 编辑页删除需确认；应用层显示撤销提示，恢复同一主键的完整账单。
- 待确认卡片将信息、主要操作和原通知分层，重新识别与丢弃位于更多菜单。
- 首页与统计共享月份和汇总口径，保留今年与累计支出概览。图表提供每日文字明细。
- 移除六方案选择及预览代码，旧外观偏好被清理，其他设置与账单不变。
- 月份、分类、列表滚动与编辑草稿支持状态恢复；跨日及回到前台刷新日期。通知冷启动使用缓冲 Channel，避免 UI 收集前丢失跳转事件。

## 平台兼容检查

Android Lint 发现原项目收起通知栏的两处系统广播需要普通应用无法取得的权限，改为已启用读屏服务的 `GLOBAL_ACTION_DISMISS_NOTIFICATION_SHADE` 操作；无障碍服务未运行时仍保持安全的空操作。官方说明：https://developer.android.com/about/versions/12/behavior-changes-all#close-system-dialogs

为 ML Kit 引入的旧版 Fragment 增加 1.3.0 最低版本约束，满足现有 ActivityResult API 的要求。

## 验证方式

```sh
./gradlew testDebugUnitTest assembleDebug assembleDebugAndroidTest
./gradlew connectedDebugAndroidTest
```

单元测试覆盖跨年月份边界、当前月/历史月日均、闰年、退款、分类 ID 筛选、空月份、排序及未来月份隔离。交互测试覆盖月份跨页面与 Activity 重建恢复、规则/分类入口、新增后编辑、待确认入账、通知在已保存状态下跳转及删除撤销。

APK 使用 debug 签名，适合本次体验验证。若与手机现有版本签名不同，不能直接覆盖安装；应先通过现有应用导出备份，避免卸载导致数据丢失。正式发布需要沿用原签名。

真机待验：真实支付通知、无障碍读屏、后台存活、厂商系统行为及系统键盘。模拟器验证不能替代这些检查。
